# 나만의 리멤버 앱

## 설계 문서

명함을 촬영하면 AI가 자동으로 정보를 추출하여 저장하고,
상대방에게 인사 이메일을 보내는 **개인용 스마트폰 웹앱**

---

## 목적

- 명함을 디지털로 관리하여 **분실/망각 방지**
- 명함 교환 후 즉시 **인사 이메일 발송**으로 비즈니스 관계 강화
- **디지털 명함 페이지**로 전문적인 인상 전달

---

## 기술 스택

| 역할 | 기술 | 선택 이유 |
|------|------|-----------|
| 프론트엔드 | Next.js (React) | 모바일 퍼스트 PWA, SSR 지원 |
| 호스팅 | Firebase Hosting | Firebase 생태계 통합, 빠른 배포 |
| 인증 | Firebase Auth | 간단한 Google 소셜 로그인 |
| 데이터베이스 | Firestore | 빠른 검색, 실시간 동기화 |
| AI OCR | Gemini 2.5 Flash | 명함 인식 정확도 높음, 저비용 |
| 이메일 | EmailJS | 무료, Gmail에서 직접 발송 |
| 백업 | Google Sheets | 비개발자 친화적, 눈으로 확인 가능 |

---

## 화면 구성 (5개)

1. **홈/명함 목록** — 카드 리스트, 검색, 필터
2. **명함 촬영/등록** — 카메라 촬영 → AI 분석 → 자동 채움
3. **명함 상세** — 전체 정보, 원터치 전화/이메일
4. **내 디지털 명함** (공개) — 누구나 링크로 접속
5. **설정** — 내 정보 편집, Sheets 내보내기

---

## 1. 홈/명함 목록 화면

- 저장된 명함 카드 리스트 (이름, 회사, 직책 표시)
- 상단 **검색바** (이름, 회사, 직책으로 검색)
- 만난 장소별 **필터 탭**
- 하단 **플로팅 버튼**: 명함 촬영
- 정렬: 최신순 기본

---

## 2. 명함 촬영/등록 화면

- 카메라 촬영 또는 갤러리에서 사진 선택
- 사진 → **자동 압축** → **Gemini AI 분석**
- AI 결과를 폼에 자동 채움 (사용자가 확인/수정)
- 입력 필드: 이름, 회사, 직책, 이메일, 전화, 주소, 메모, 만난 장소
- **중복 체크**: 이메일 > 전화번호 > 이름+회사 순
- 저장 후 "인사 이메일 보내기" 옵션 표시

---

## 3. 명함 상세 화면

- 명함 정보 전체 표시 + 썸네일 이미지
- **원터치 전화** 걸기 버튼
- **원터치 이메일** 보내기 버튼
- 메모 / 만난 장소 편집
- 인사 이메일 발송 상태 표시
- 명함 정보 수정/삭제

---

## 4. 내 디지털 명함 (공개)

- 인증 불필요 — **누구나 링크로 접속** 가능
- 내 이름, 회사, 직책, 이메일, 전화번호 표시
- 별도 `publicProfile` 컬렉션에서 최소 정보만 노출
- 경로: `/card/[slug]`
- 깔끔하고 전문적인 디자인

---

## 핵심 흐름: 명함 저장

1. 카메라로 명함 촬영 (또는 갤러리 선택)
2. 브라우저에서 **이미지 압축**
3. 압축 이미지를 **Cloud Function**으로 전송
4. Cloud Function이 **Gemini 2.5 Flash** 호출 → JSON 반환
5. 결과를 화면 폼에 자동 채움
6. 사용자 확인/수정 후 저장
7. **중복 체크** 실행
8. Firestore에 저장 + 썸네일 저장
9. "인사 이메일 보낼까요?" 다이얼로그

---

## 핵심 흐름: 이메일 발송

1. 사용자가 "이메일 보내기" 선택
2. **EmailJS**로 인사 이메일 발송 (내 Gmail에서 직접)
3. 이메일 내용: 인사말 + 내 연락처 + **디지털 명함 링크**
4. 발송 성공 시 `greetingEmailSent = true`

## 중복 감지 로직

1. **1차: 이메일 일치** — 가장 신뢰도 높음 (정확 매칭)
2. **2차: 전화번호 일치** — 번호 정규화 후 비교
3. **3차: 이름 + 회사 일치** — 둘 다 일치할 때만

중복 발견 시 → 기존 명함 보여주고
**"업데이트"** 또는 **"새로 저장"** 선택

---

## 보안

- **API 키 보호**: Gemini/Sheets 키는 Cloud Function 환경변수에만 저장
- **Firestore 보안 규칙**: 본인 데이터만 읽기/쓰기
- **공개 프로필**: 읽기만 허용, 쓰기는 본인만
- **EmailJS**: 서비스 ID/템플릿 ID만 클라이언트에 노출
